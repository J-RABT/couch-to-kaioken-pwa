# Couch to Kaioken

A personal adaptive fitness PWA. Strength, endurance, speed and mobility; real performance, locked personal goals, and a training saga through Kaioken.

This repository contains the compiled static app only. All profile, assessment, workout and measurement data is stored in the user's browser. There are no accounts, paid APIs, analytics or cloud fitness uploads.

Open the GitHub Pages site over HTTPS, then use Chrome's **Install app** / **Add to Home screen** on Android or Chromebook. Load it once online for offline availability. Export JSON backups regularly from Settings; browser storage is local to each device. Use JSON export/restore to transfer between devices.

The Power Level model is gamified, not a medical measurement. Stop activities that hurt. Later transformations appear as future chapters; their training content is intentionally not yet authored.

The app shell and assets use original CSS/SVG illustrations. This is an independent personal fan project, not affiliated with the Dragon Ball rights holders.
